# UI/UX V2.0 — Marketing site + Owner dashboard (PRD)

Date: 2026-10-07 · Owner: Karan · Executor: Claude (autonomous, phase by phase, ship + live smoke each)

## Why

The marketing site still describes v0.1: wrong prices ("Growth $60", "unmetered conversations"),
"AI sales agent" wording (we never say agent), retired claims (Whisper/ElevenLabs, recipe-card
editor, "five paying beta merchants", S3/Redis jargon, `coupons.suggest(cart)`), dead footer
links, and the assistant is called Olivia in one place and Sage in another. The owner
dashboard works but reads like an admin panel: a flat list of 11 links, raw tables, numbers
without meaning, no sense of "is this working for me?".

V2 goal: a site that sells with confidence and tells the truth, and a dashboard a non-technical
shop owner opens and understands in five seconds.

## Principles

1. **Truth first.** Every price, limit and capability on the site matches the product and
   billing code. No invented stats or logos.
2. **Shows its work.** The product's signature is honesty (receipts, "On your website"
   timeline). The design carries that motif: green ticks = real, confirmed outcomes.
3. **Owner-first.** Answer first, numbers second, jargon never. Every number says what it
   means ("12 orders after a chat") and every page says what to do next.
4. **One voice.** The assistant is **Olivia** everywhere on our own site (demo store persona
   switched to `concierge` = Olivia). Merchants' assistants keep their own names in-product;
   the dashboard says "your assistant".
5. **No "agent" language** in customer-facing copy (standing rule).
6. Accessible: AA contrast, focus states, reduced-motion respected, works at 390px.

## Design system V2

| Token | V1 | V2 |
|---|---|---|
| Sans | Inter | **Geist** (crisp, modern, tabular numbers) |
| Display accent | none | **Instrument Serif** italic for 1–3 emphasis words per headline |
| Mono | JetBrains Mono | **Geist Mono** |
| Dark ground | #06060a cool | #08080c ink, warm ivory text #f3f1ea |
| Light ground | pure white | paper #faf8f4 |
| Brand accent | violet→cyan gradients everywhere | violet kept as brand, **signal green** (#3ddc97) = live / done / money; gradients used sparingly |
| Cards | flat border | border + 1px inner top highlight + soft depth; hover lift 2px |
| Motion | per-element fades | one orchestrated stagger per section; spring ticks; reduced-motion off |

Shared primitives (web/src/components/v2): `Eyebrow`, `SerifEm`, `Tick`, `SectionHead` (restyled),
dashboard `DashHeader`, `StatCard`, `EmptyState`, `Badge`, `Meter`.

- Dashboard showed ₹ amounts with a $ sign — money now formats in the store's own currency (orders → catalog fallback).

- Settings hydration error (server-UTC vs browser-local time) re-rendered the whole document and dropped dark mode. Times now format in the browser (`LocalTime`).
- Conversation times showed in UTC (9:18 pm IST call shown as 3:48 pm) — now viewer-local.
- Funnel showed "176% of previous" (cart adds are per item) — rates over 100% hidden, bars clamped.
- Duplicate React keys when a session is recorded twice.
- Signup test rewritten to current behaviour (was failing before this work).
- Demo store widget persona switched Sage → Olivia (DB `merchants.persona_id` for SM-XPK2EN = `concierge`; revert with `calm-clinician`).
