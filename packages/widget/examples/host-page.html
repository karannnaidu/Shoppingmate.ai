Pretend merchant page

This is a local smoke harness for the shoppingmate widget bundle. Open dev tools, talk to Sage in the bottom-right pill.

Make sure: (a) pnpm --filter @shoppingmate/api dev is running, (b) you've provisioned a dev merchant via pnpm --filter @shoppingmate/cli exec -- shoppingmate provision --domain=localhost --name="Dev Store", and (c) the merchant id below matches what the CLI printed.

SHOPPINGMATE_API_BASE=http://localhost:3000 pnpm --filter @shoppingmate/widget dev

Then refresh this page from http://localhost:5174/host-page.html (or wherever you serve it).
